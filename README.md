# 🐍 Trying Python Libraries

A collection of beginner-friendly Python projects that explore popular Python libraries through hands-on examples. This repository is designed for learning, experimenting, and understanding how different libraries can be used to build practical applications.

---

## 📖 About

This repository contains small projects and scripts created while learning various Python libraries. Each script demonstrates the basic usage of a library and serves as a reference for beginners.

Whether you're generating QR codes, experimenting with text processing, or exploring new packages, this repository is a great starting point for learning Python libraries through practice.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/jillasrivardhan/Trying_Python_Libraries.git
```

### 2. Navigate to the Project

```bash
cd Trying_Python_Libraries
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

> **Note:** If a `requirements.txt` file is not available, install the required libraries manually.

Example:

```bash
pip install qrcode pillow nltk
```

---

## ▶️ Running the Programs

### Run the QR Code Generator

```bash
python qr.py
```

### Run the Tokenizer Example

```bash
python tokenizer.py
```

### Run the Basic Python Script

```bash
python hello.py
```
